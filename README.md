# EconLab

EconLab 是运行在本机浏览器中的经济学研究助手，通过 Codex 阅读论文，维护文献库、方法库和工具库，并调用已验证的工具处理适用范围内的研究问题。


### 1. 准备环境

- **Windows + Python 3.11 或以上版本**，终端中可以执行 `python`。
- **Codex CLI**，终端中可以执行 `codex`。使用 npm 安装时，先安装 Node.js，再执行：

  ```powershell
  npm install -g @openai/codex
  ```

- **MATLAB 按需安装**：只有运行 MATLAB 类型的工具时才需要，并须具备作者代码要求的工具箱。普通文献导入、追问和 Python 工具不需要 MATLAB。

### 2. 启动项目

在包含 `econlab` 文件夹的项目根目录打开 PowerShell，执行：

```powershell
.\econlab\start.cmd
```

启动脚本会检查 Python 依赖，缺少依赖时创建虚拟环境并安装 `requirements.txt`。首次安装依赖需要联网。服务启动后会打开浏览器，也可以手动访问：

**http://127.0.0.1:8765**

进入右上角的设置，点击“登录 Codex / ChatGPT”，完成登录后刷新连接并测试。每位使用者使用自己的 Codex 账户及可用额度。

### 3. 开始使用

1. 在**文献库**导入 PDF，勾选 AI 分析，等待逐页阅读完成。
2. 查看知识卡和关联方法，通过论文追问补充理解，或人工修改、审核记录。
3. 在**工具库**补齐作者代码、输入数据和参考结果，封装并审核代码，点击“使用作者基准验证”。
4. 在**问题求解**中输入问题及数据条件，确认适用方法和参数后执行计算。

新导入的论文可以先生成方法和工具候选；缺少代码、数据或验证记录的候选暂不能用于自动求解。

### 4. 停止项目

在项目根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\econlab\stop.ps1
```

## 运行原理

### 文献导入与知识库更新

```text
导入 PDF → Codex 阅读全部页面 → 整理知识卡和方法 → 建立或更新工具候选
```

PDF 会逐页转成图像，分批交给 Codex 视觉阅读，**不使用 OCR**。原 PDF 自带的文本层保留用于原文查看和引文匹配，原件与页码保留，便于回查依据。

三个库通过来源与关联关系衔接：

| 知识库 | 保存的内容 | 作用 |
| --- | --- | --- |
| 文献库 | 论文原件、作者与版本、附件、逐页内容、知识卡和证据 | 提供研究依据 |
| 方法库 | 问题、假设、机制、方程、步骤、数据要求、适用范围和来源 | 判断方法是否适合当前问题 |
| 工具库 | 封装代码、运行环境、参数、作者数据、参考输出和验证记录 | 实际执行计算 |

添加附件会触发 AI 检查相关记录；删除论文会同步清理关联关系，仅属于该论文的方法和工具随之删除，共享记录保留并重新核对。三个库均支持人工修改、审核和修订追踪，相关变更会使旧工具验证失效。

### 论文追问与记忆

每篇论文绑定一个独立的 Codex 持续会话。本地同时保存完整对话和研究摘要，每次追问都会补入该论文最新的三个库记录。重启后优先恢复原会话；原会话不可恢复时，使用本地历史和摘要重建上下文。

AI 可以根据明确的修改要求或证据提出结构化更新，由程序检查来源范围和版本后保存。更新保留修订记录，仍可人工审核与纠正。

### 方法复现与问题求解

复现阶段运行作者代码及原始输入，并与独立参考结果逐项比较：非零参考值的相对误差必须严格小于 **10%**；零值需单独设置绝对容差。验证通过后，工具才可用于后续求解。验证绑定代码、方法版本和材料哈希，变更后需要重新验证。

```text
用户问题和数据条件 → 检索方法库 → Codex 比较适用条件
→ 补充缺失信息、确认方案 → 调用已验证工具 → 返回数值、解释、依据和运行记录
```

Codex 负责阅读、方法比较和结果解释，数值计算由本机 Python 或 MATLAB 工具执行。工具代码以本机账户权限运行，执行前须审核代码及依赖。没有合适方法、必要数据或已验证工具时，系统返回缺口和补充要求。

网页服务和数值计算运行在本机；AI 分析需要联网，会将相关论文页面和任务上下文发送到 Codex 在线服务。

### 数据保存

默认数据目录为项目内的 `econlab/.local/`，其中保存 SQLite 数据库、论文附件、对话和运行结果。重启项目不会清空这些资料；备份时先停止服务，再复制整个目录。

公开提交源码时，应排除本地知识库、论文原件、作者材料和运行环境；源码首次启动时需自行导入论文。第三方组件及项目许可证状态见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
