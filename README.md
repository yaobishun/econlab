# EconLab

通过 Codex 阅读经济学论文，将文献中的模型整理为可检索的方法记录和可执行工具，再用经过验证的工具回答研究问题。

项目采用 **FastAPI + SQLite + 原生 JavaScript**，运行在本机浏览器中。AI 使用本机已登录的 Codex 账户，模型计算由 Python 或 MATLAB 执行。

## 功能

| 页面 | 功能 |
| --- | --- |
| 文献库 | 导入与删除 PDF，管理附件、知识卡和原文证据；论文追问、人工修改与审核；查看复现任务和执行日志 |
| 方法库 | 保存模型的问题、假设、机制、方程、求解步骤、数据要求、适用范围及来源文献 |
| 工具库 | 管理方法封装、输入输出、依赖环境与验证记录，执行复现验证和计算 |
| 问题求解 | 根据研究问题比较方法，检查数据与适用条件，调用已验证工具，返回数值、解释、依据和运行记录 |

以论文为项目、核心模型为方法、实验为验收单位。同一模型的多个实验复用公共求解器，各自绑定输入、参数和独立参考。实验清单在论文详情页维护，不增加第四个知识库。三库与清单支持人工修改、版本和审核；删除论文同步处理关联记录，共享方法和工具保留并重新核对。

## 快速开始

### 环境要求

- Windows，Python 3.11 或以上版本。
- 已安装 Codex CLI，并有可用的 Codex / ChatGPT 登录账户及额度。
- MATLAB 为可选依赖，仅运行 MATLAB 工具时需要，以及对应工具要求的工具箱。

Codex CLI 可通过 npm 安装，使用此方式需先安装 Node.js：

```powershell
npm install -g @openai/codex
```

### 启动

```powershell
git clone https://github.com/yaobishun/econlab.git
cd econlab
.\econlab\start.cmd
```

启动脚本检查 Python 依赖，缺失时创建虚拟环境并安装。首次安装需要联网。启动后访问 **http://127.0.0.1:8765**。

在右上角设置中登录 Codex / ChatGPT，刷新连接并测试。无需配置 AI API Key。

### 使用

1. 在文献库导入 PDF，保留完整分析与自动准备复现工具选项。
2. 在论文详情查看核心模型、完整实验清单、图表覆盖、材料缺口和执行日志。
3. 默认自动模式：Codex 获取材料、适配数据和准备求解器，再自动核对模型、代码、输入、参考及完整清单。系统自动创建所需 Python 环境、安装声明依赖并检测环境，随后按依赖执行实验。
4. 失败时 Codex 根据真实检查、安装和运行日志修复，再重新检查与验收。全部必验项通过后，在问题求解页确认研究方案并实际计算。

论文详情的 **复现报告** 汇总五部分：模型主体和假设理由、从目标与约束到均衡条件的推导、参数/数据/代码来源、逐项结果对照，以及审核返修记录。结果直接读取实际运行，支持同字段柱状图、完整对照 CSV、运行包下载和打印保存 PDF。运行包包含当次代码、输入、环境记录与复跑说明，作者材料的再分发条件仍以原来源为准。

“用 AI 补充报告说明”整理尚未结构化的推导与解释，不重新执行实验。AI 自行设定的参数和补充推导单独标记，也可人工修改，保留版本。报告终审独立于数值验收；修改说明或确认报告不会改变计算结果、开放工具或使失败项通过。模型、材料、代码或运行记录变化后，旧说明提示需核对，旧终审失效。

常规流程无需逐次人工放行或手动安装依赖。真实材料缺失、软件授权不可用、研究目标或科学假设需要决定时才暂停。设置页可切换“人工审核后执行”；各库保留人工修改、审核和提出异议的入口，自动模式不会覆盖人工异议。

任务支持停止与继续，工作区和会话会保留。材料缺失、账户额度不足或运行失败时，论文页会显示原因。

### 停止

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\econlab\stop.ps1
```

## 工作原理

### 从论文到工具

```text
导入 PDF → 全页视觉阅读 → 核心模型与完整实验清单
→ 图表覆盖、实验依赖核对 → 获取材料、适配数据、准备公共求解器
→ 自动检查模型/工具 → 自动配置环境 → 核对并冻结本版实验计划
→ 按依赖逐项准备与运行 → 后端逐项验收 → 全部必验项通过后开放方法
                         ↓ 失败
                  Codex 读取日志修复 → 自动复查、续跑
```

PDF 全部页面转为图像，分批交给 Codex 阅读，不使用 OCR。原 PDF 文本层保留用于原文展示和引文匹配。

应用通过 Codex `app-server` 接口调用已登录账户。复现 Agent 在每篇论文的独立工作区内检查文件、编写脚本、执行数据适配并根据错误修正；应用提供公开材料搜索下载、原页查看、实验固定和成果提交工具。代码可来自作者公开材料，也可依据论文实现。

研究情景、可执行参数、输入文件、单位和原文观察值分别保存，说明文字不会直接作为函数参数。实验清单分批保存草稿与错误；新增附录增量核对，保留已完成的正文分析。

Agent 提交结构化成果，由后端检查来源、版本与三库映射后保存。自动检查与人工审核分别记录，不冒充人工确认。运行器实际计算并比较参考结果；AI 不能自行设置“数值验证通过”。修正任务会收到对应版本的运行日志和实际输出，改动后的代码与配置需重新检查。

### 验证与求解

复现使用真实输入和独立参考结果。默认对未舍入输出逐项验收：非零参考值的相对误差必须**严格小于 10%**，零参考值使用预先指定的绝对容差。用户明确授权后，可为指定指标记录论文显示精度规则：仅接受原文末位舍入区间内的差异，原始数值和相对误差仍完整保留，规则变更后重新运行验收。参考文件不进入计算工作区，验证记录绑定代码、方法版本和材料哈希，相关变更后需重新验证。

```text
研究问题与数据条件 → 检索方法库 → 比较假设、数据和适用范围
→ 补充缺失信息、确认方案 → 调用已验证工具 → 返回结果与依据
```

默认严格模式：完整实验清单经过自动检查或人工核对，当前版本所有必验数值/曲线实验通过、定性项完成单独核对后，相关方法才开放求解。单个工具或实验通过不能解锁整篇论文。定性核对不会计作数值验证；排除项目须说明原因并经人工确认，覆盖率保留排除数。缺独立参考时保留缺口，不能用自身输出充当基准。曲线额外检查预先固定的形状、临界点和区间。

材料不齐的任务保留缺口，其他有独立输入的实验可继续运行。作者已提供校准快照时，可以绑定实际读取的数据文件满足下游输入依赖；这不会把上游重建任务标为通过。无关实验补齐配置不会撤销已有有效数值证明，受影响的代码、输入和依赖变更仍需重验。

任务步骤结束、实验通过和整篇完成分别记录。超时、额度不足和重启保留清单、工作区与运行记录。计划、代码、模型、输入、参考、依赖或环境变化时，旧证明需重新核对或重跑。问题求解范围仍受模型假设和真实数据限制。

### 会话与数据

每篇论文保留问答和执行会话，并共享结构化项目记忆：研究目标、人工意见、清单版本、尝试与错误、待处理事项和下一步。完整历史保存在本地，提供给模型的是相关原文、最新状态和摘要。重启后恢复会话和工作区；原生会话无法恢复时，使用本地历史重建上下文。

数据默认保存在 `econlab/.local/`，包括数据库、论文附件、会话、工作区和运行结果。备份时停止服务并复制该目录。`.local/` 和 `.venv/` 已加入 `.gitignore`，仓库不附带本地论文库与测试数据。

网站为本地单机服务。AI 阅读与分析需要联网，相关论文页面和任务上下文会发送至 Codex 在线服务。Agent 使用限定工作区的写入沙箱；未经人工确认的 Python / MATLAB 工具由 Codex 原生命令沙箱运行，只允许写入本次运行目录，关闭网络；人工确认的工具保留本机执行方式。依赖安装只接受包名与版本约束，不执行仓库安装脚本。MATLAB 及其授权、工具箱需在本机可用。

## 代码结构

```text
econlab/
├── app.py                          # FastAPI 接口与本地访问控制
├── catalog.py / store.py            # 三库映射、版本、审核与 SQLite 存储
├── engine.py                       # 论文分析、问答、任务和问题求解编排
├── codex_bridge.py / provider_bridge.py  # Codex app-server 接入
├── pdf_visual.py                   # PDF 逐页图像输入
├── materials.py                    # 公开材料搜索、下载、解包与来源记录
├── execution_agent.py              # Agent 工作区、宿主工具与成果校验
├── manifest.py                     # 实验清单结构化输出、历史草稿兼容与图表映射
├── experiments.py                  # 实验清单、依赖、审核绑定、验证证明与严格资格
├── reproduction_report.py          # 五部分报告、来源与版本、逐项对照、运行包和终审
├── workflow.py                     # 持久化总控、清单审计、批量执行与修复调度
├── automation.py                   # 自动检查与版本绑定，不冒充人工审核
├── sandbox_runtime.py              # Codex 命令沙箱中的正式计算
├── reproduction.py                 # 复现准备、审核与验证流程
├── runner.py / environments.py     # Python / MATLAB 执行与依赖环境
├── static/                         # 网页界面
├── tests/                          # 自动化测试
└── tools/                          # 隔离验证、浏览器检查与源码打包脚本
```

## 开发与测试

在仓库根目录执行：

```powershell
python -m venv econlab\.venv
.\econlab\.venv\Scripts\python.exe -m pip install -r econlab\requirements.txt
.\econlab\.venv\Scripts\python.exe -m unittest discover -s econlab\tests -v
```

[agent_capability_probe.py](econlab/tools/agent_capability_probe.py) 可测试实际 Codex 文件与执行能力；[agent_workflow_validation.py](econlab/tools/agent_workflow_validation.py) 可建立隔离库验证复现流程。这些在线检查需要登录账户并消耗额度，生成材料保存在 `econlab/.local/validation/`。

可导出当前论文的真实验收记录（不启动计算，也不改变任何审核状态）：

```powershell
.\econlab\.venv\Scripts\python.exe econlab\tools\paper_acceptance_report.py --paper-id <论文ID>
```

报告写入 `.local/validation/paper-<论文ID>/`，逐项列出状态、实际运行、误差、输入和参考。只有完整清单的所有必验项通过时才标记整篇通过。
